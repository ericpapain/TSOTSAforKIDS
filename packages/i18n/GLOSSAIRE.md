# Glossaire bilingue obligatoire — TSOTSA Kids (FR / EN)

Ce glossaire fait foi pour l'ensemble des traductions de la plateforme TSOTSA Kids (applications web et mobile).

| Français | English |
|---|---|
| soignant / espace soignant | caregiver / caregiver portal |
| membre de la famille | family member |
| prise (alimentaire) | intake |
| confirmer une prise | confirm an intake |
| plan de prises | intake plan |
| équivalents locaux | local equivalents |
| aliment / plat / ingrédient | food / dish / ingredient |
| recette (de cuisine) | recipe |
| environnement de recette | staging (ne jamais traduire par « recipe » !) |
| fiche (patient) | record |
| évaluation | assessment |
| courbes de croissance OMS | WHO growth charts |
| émaciation | wasting |
| retard de croissance | stunting |
| insuffisance pondérale | underweight |
| malnutrition aiguë sévère (MAS) | severe acute malnutrition (SAM) |
| malnutrition aiguë modérée (MAM) | moderate acute malnutrition (MAM) |
| anti-nutriment | antinutrient |
| rappel / relance | reminder / follow-up reminder |
| heures calmes | quiet hours |
| C'est donné / Plus tard / Pas donné | Given / Later / Not given |
| consentement | consent |
| compte en attente de vérification | account pending verification |
| import, double validation | import, two-step approval |
| F-75, F-100, Plumpy'Nut, Plumpy'Sup | inchangés (noms de produits) |
| noms de plats locaux (Condrès, Gari digari…) | inchangés |
| noms scientifiques | inchangés |
