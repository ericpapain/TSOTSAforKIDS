# Guide d'Utilisation — Espace Famille & Parents

Bienvenue dans le guide du module **« Santé et bien-être de mon enfant »** de l'application TSOTSA for KIDS.

---

## 1. À quoi sert cet espace ?

Ce module vous permet de :
- Noter facilement tout problème de santé observé chez votre enfant (fièvre, toux, diarrhée, fatigue...).
- Signaler un incident survenu pendant un repas (vomissements, refus soudain de s'alimenter).
- Être guidé immédiatement si votre enfant présente des signes nécessitant une consultation médicale urgente.
- Retrouver l'historique de tous les bilans de santé pour en parler sereinement avec votre médecin ou infirmier.

---

## 2. Comment signaler un problème de santé ?

### Sur l'Application Mobile (Android)
1. Ouvrez l'application et rendez-vous dans le profil de votre enfant.
2. Appuyez sur le bouton vert **« Santé et bien-être de mon enfant »**.
3. Choisissez **« Signaler un problème »**.
4. Suivez les 5 étapes simples :
   - **Quand cela a-t-il commencé ?** : sélectionnez la date ou l'option rapide (« Aujourd'hui », « Hier »).
   - **Que constatez-vous ?** : touchez les cartes correspondant aux signes observés.
     > ⚠️ **Alerte immédiate** : si vous cochez un signe grave (convulsions, enfant somnolent qui ne réagit pas, respiration très rapide), un message rouge s'affiche instantanément avec le numéro d'urgence à appeler sans attendre.
   - **Quelques précisions** : répondez aux questions courtes (température constatée, fréquence des selles, etc.).
   - **Avez-vous déjà donné quelque chose ?** : indiquez si vous avez administré un médicament (paracétamol...), un soluté de réhydratation ou une tisane.
   - **Vérification** : relisez le récapitulatif et appuyez sur **« Transmettre »**.

### Pendant un Repas
Si un problème survient au moment où vous donnez un repas ou un lait thérapeutique dans l'application :
1. Appuyez sur le bouton **« Signaler un problème de santé »** présent sur l'écran du repas.
2. Le signalement est automatiquement rattaché à ce repas pour informer le médecin d'une éventuelle intolérance.

---

## 3. Consulter l'historique de santé

À tout moment, depuis le hub « Santé et bien-être », appuyez sur **« Historique de santé »** :
- Vous y retrouverez chaque événement consigné par ordre chronologique.
- Les bilans sont rédigés dans un langage clair et rassurant.
- Vous pouvez vérifier si votre soignant référent a pris connaissance de votre signalement.
